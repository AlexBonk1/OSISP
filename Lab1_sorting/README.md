## LR 1 ОСиСП

Инструкция по запуску

1. Скомпилировать c++ файл и запустить его 

```
g++ maindump.cpp -o test
./test
```

2. Активировать python venv и установить pandas и mathplotlib

```
python -m venv .venv
source .venv/bin/activate
pip install pandas mathplotlib
```

3. Запустить python скрипт отрисовки графика

```
python plot.py
```
